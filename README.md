# 🍽️ Restaurant Management System

A web-based Restaurant Management System developed using Python and Django.

## 📌 Project Overview

This project helps manage restaurant menu items, customer orders, order status, and sales information through a simple web interface.

## 🚀 Features

- 🍽️ Menu Management
- 📝 Place Customer Orders
- 📋 View My Orders
- ✏️ Edit Orders
- 🗑️ Delete Orders
- ⏳ Order Status Management
- 👨‍💼 Django Admin Panel
- 📊 Restaurant Dashboard
- 💰 Total Sales Calculation
- 📋 Recent Orders

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
